# nixos-installer

Актуальный `nixos-base` добавляет установщик в системный профиль автоматически. Этот компонент доступен для других flakes и для существующих селекторов, где он управляет версией и переключателем пакета.

Добавьте `(import (modulesRoot + "/nixos-installer"))` в список `modules` в `config.nix`. Укажите каталог базового flake в поле `flakeDir` этого же файла. После активации команда `nixos-installer` открывает редактор с конфигурацией хоста. На странице просмотра кнопка **Rebuild** сохраняет настройки и сразу запускает `nh` для выбранной системы. На Linux без настроенного селектора та же команда открывает мастер установки.

Модуль скачивает готовый бинарник для выбранной ОС и архитектуры. Версия и SHA-256 для каждого файла закреплены в `release.json`. [Релизы установщика](https://github.com/acup1/nixos-installer/releases)
