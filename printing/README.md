# Модуль `printing`

* **Экспорт**: `nixos`
* **Назначение**: Пакеты и драйверы подсистемы печати.

## Структура

* `default.nix` — экспортирует конфигурацию NixOS.
* `nixos.nix` — подключает `packages/`.
* `packages/printing.nix`:
  * Пакет сервера печати `cups`.
  * Драйвер для многофункциональных устройств и принтеров `fxlinuxprint`.
