# Модули `WM-DE`

* **Экспорт**: `nixos` + `home` (раздельные бандлы для каждого окружения)
* **Назначение**: Оконные менеджеры и рабочие столы Wayland/X11 с общим слоем интеграции.

## Структура

Модуль сгруппирован в независимые бандлы, каждый из которых подключает общий слой `common`:

### `common/`
Общий базис для всех графических сред:
* Экранный менеджер GDM.
* Порталы XDG Desktop Portal (включая GTK-портал).
* Поддержка устройств ввода, тачпадов и датчиков планшета.
* Аудиосервер, управление питанием и интеграция графики.
* Панель Waybar с кастомной темой.
* Экранная виртуальная клавиатура WaylandKB.
* Оболочка DankMaterialShell (DMS).

### `hypr/`
* Композитор Hyprland.
* Утилита создания скриншотов Grimblast.
* Lua-скрипты и модульная конфигурация хоткеев, правил окон и анимаций.
* Автоматический импорт `../common/`.

### `niri/`
* Бесконечный горизонтально-скроллящийся тайловый композитор Niri.
* Утилита автоматического поворота экрана `iio-niri`.
* Файл настроек `config.kdl`.
* Автоматический импорт `../common/`.

### `drift/`
* Тайловый оконный менеджер DriftWM.
* Патч для жеста выхода из режима overview щипком тачпада.
* WLR-порталы, скрипты автоповорота.
* Автоматический импорт `../common/`.

### `gnome/`
* Полнофункциональное рабочее окружение GNOME.
* Расширение поворота дисплея.
* Автоматический импорт `../common/`.
