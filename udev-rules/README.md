# Модуль `udev-rules`

* **Экспорт**: `nixos`
* **Назначение**: Дополнительные общесистемные правила udev для оборудования.

## Структура

* `default.nix` — экспортирует конфигурацию NixOS.
* `nixos.nix` — подключает `configuration/`.
* `configuration/udev_rules.nix`:
  * Системные правила udev для корректного обнаружения и настройки прав доступа к подключаемым USB-устройствам и периферии.
