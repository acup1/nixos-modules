# Модуль `sound`

* **Экспорт**: `nixos`
* **Назначение**: Звуковая подсистема и управление медиа-воспроизведением.

## Структура

* `default.nix` — экспортирует конфигурацию NixOS.
* `nixos.nix` — подключает `packages/`.
* `packages/sound.nix`:
  * `pipewire` — звуковой сервер нового поколения с низкой задержкой.
  * `playerctl` — командная строка для управления медиаплеерами через протокол MPRIS.
