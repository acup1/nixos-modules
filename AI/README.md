# Модуль `AI`

* **Экспорт**: `nixos`
* **Назначение**: Подготовка окружения для запуска локальных больших языковых моделей (LLM).

## Структура

* `default.nix` — точка входа модуля, экспортирует конфигурацию NixOS (`nixos = import ./nixos.nix;`).
* `nixos.nix` — подключает пакеты из каталога `packages/`.
* `packages/AI.nix` — заготовки для развертывания локального сервиса `ollama` (`services.ollama.enable = true;`) и установки интерфейсов (LM Studio).
