# Bluetooth

Выберите компонент `bluetooth` в `nixos-installer`, чтобы включить BlueZ в NixOS.
После применения откройте настройки Bluetooth в рабочем окружении или запустите `bluetoothctl`.
Команда `bluetoothctl show` показывает состояние адаптера.

По умолчанию BlueZ включает адаптер при загрузке. Это можно изменить в настройках компонента.
