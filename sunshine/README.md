# Модуль `sunshine`

* **Экспорт**: `nixos` + `home`
* **Назначение**: Сервер стриминга рабочего стола и игр Sunshine в GNOME, в том числе без подключённого монитора.

## Структура

* `default.nix` — экспортирует обе части: `nixos = import ./nixos.nix;` и `home = import ./home.nix;`.
* `nixos.nix` — подключает `WM-DE/gnome` и `configuration/`.
* `home.nix` — подключает `home_packages/`.
* `configuration/sunshine.nix`:
  * Служба Sunshine с правами захвата KMS.
  * Открытие необходимых UDP/TCP портов в фаерволе.
  * Автологин пользователя в GNOME через GDM.
  * Загрузка драйвера VKMS для виртуального DRM-дисплея `Virtual-1` без HDMI-заглушки.
  * Скрипты `sunshine-client-mode` и `sunshine-default-mode` для изменения разрешения и частоты через Mutter (`gdctl`).
  * Скрипт `sunshine-headless` ожидает готовности GNOME и настраивает виртуальный экран перед каждым запуском Sunshine.
* `home_packages/gnome/` — отключение гашения экрана, автоматической блокировки и сна от сети в пользовательской сессии.

## Виртуальный экран

Базовый режим — `1920x1080@60`, масштаб — 1. При подключении Moonlight
модуль пытается выбрать запрошенный клиентом режим из доступных VKMS.
Если такого разрешения или частоты нет, используется базовый режим.
После отключения клиента базовый режим восстанавливается.

Этот профиль оставляет `Virtual-1` единственным активным выходом GNOME.
Sunshine захватывает его через KMS с `CAP_SYS_ADMIN` (индекс `output_name = 0`);
старые настройки Hyprland и WLR больше не нужны.
Совместимость захвата VKMS и аппаратного кодирования зависит от GPU и
драйвера; её нужно проверить на целевом Linux-хосте.
