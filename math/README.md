# Модуль `math`

* **Экспорт**: `nixos`
* **Назначение**: Математические расчеты, численное моделирование и цифровая обработка сигналов.

## Структура

* `default.nix` — экспортирует конфигурацию NixOS.
* `nixos.nix` — подключает `packages/`.
* `packages/math.nix`:
  * Калькулятор с поддержкой единиц измерения: `qalculate-gtk`.
  * Среда численных расчетов: `octaveFull` с пакетами `signal` (ЦОС) и `symbolic` (символьная математика).
  * Платформа программно-определяемого радио (SDR): `gnuradio`.
