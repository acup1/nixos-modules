# Модуль `kicad`

* **Экспорт**: `home`
* **Назначение**: Проектирование принципиальных схем и печатных плат.

## Структура

* `default.nix` — экспортирует конфигурацию Home Manager (`home = import ./home.nix;`).
* `home.nix` — автоматически подключает модули из каталога `home_packages/`.
* `home_packages/kicad/default.nix` — установка САПР `kicad` в профиль пользователя.
