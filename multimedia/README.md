# Модуль `multimedia`

* **Экспорт**: `nixos`
* **Назначение**: Профессиональная запись видео и трансляция экрана.

## Структура

* `default.nix` — экспортирует конфигурацию NixOS.
* `nixos.nix` — подключает `packages/`.
* `packages/multimedia.nix`:
  * Студия захвата видео и проведения прямых эфиров `obs-studio`.
